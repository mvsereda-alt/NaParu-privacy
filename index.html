Политика обработки персональных данных NaParu

Дата редакции: 27 сентября 2026 года
Версия: 3.0

1. Общие положения

Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сервиса NaParu (далее — «Сервис»).

Сервис предоставляет пользователям возможность создавать и находить спортивные игры, присоединяться к ним и взаимодействовать с другими участниками.

Настоящая Политика распространяется на персональные данные, которые обрабатываются при использовании Сервиса, в том числе через Telegram-бот NaParu.

Оператор обеспечивает неограниченный доступ к настоящей Политике в соответствии с требованиями законодательства Российской Федерации о персональных данных.

2. Оператор

Оператором обработки персональных данных является физическое лицо, осуществляющее деятельность по созданию и поддержке Сервиса NaParu.

ФИО оператора: Середа Михаил Васильевич

Контакт для обращений по вопросам обработки персональных данных:
operator@bk.ru

Иные сведения об операторе, не требующиеся для информирования пользователей о порядке обработки их персональных данных, в настоящей Политике не публикуются.

3. Какие персональные данные обрабатываются

В зависимости от используемых функций Сервиса могут обрабатываться:

  • Telegram user ID;
  • имя пользователя, указанное в Telegram;
  • username в Telegram, если он указан пользователем;
  • сведения об участии пользователя в играх;
  • сведения о созданных пользователем играх;
  • роль пользователя в игре — организатор, участник или резерв;
  • сведения о действиях пользователя в Сервисе, необходимые для работы функций Сервиса;
  • сведения о предоставленном пользователем согласии на обработку персональных данных;
  • обращения пользователя в службу обратной связи и содержащаяся в них информация.

При использовании функции обратной связи пользователь может самостоятельно направить текст сообщения, фотографию или другой файл. Такие материалы обрабатываются в связи с рассмотрением обращения.

NaParu не запрашивает и не использует для организации спортивных игр паспортные данные, номер телефона, адрес проживания, медицинские сведения, биометрические данные или сведения о состоянии здоровья.

4. Цели обработки персональных данных

Персональные данные обрабатываются для следующих целей:

  1. регистрация и идентификация пользователя в Сервисе;
  2. предоставление функций Сервиса;
  3. создание спортивных игр;
  4. отображение доступных игр и информации, необходимой для принятия решения об участии;
  5. присоединение пользователей к играм и ведение состава участников;
  6. информирование пользователей об изменениях, связанных с созданными ими или выбранными ими играми;
  7. обработка обращений и обратной связи;
  8. обеспечение безопасности и корректной работы Сервиса;
  9. исполнение обязанностей оператора, предусмотренных законодательством Российской Федерации.

Обработка осуществляется только в объёме, необходимом для достижения указанных целей.

5. Правовые основания обработки

Обработка персональных данных осуществляется на основании:

  • согласия пользователя на обработку персональных данных — в случаях, когда такое согласие является необходимым;
  • иных оснований, предусмотренных законодательством Российской Федерации, когда обработка допускается без отдельного согласия пользователя.

Для использования функций NaParu, требующих обработки персональных данных, пользователю предоставляется возможность ознакомиться с настоящей Политикой и предоставить соответствующее согласие.

6. Отображение данных другим пользователям

NaParu может отображать другим пользователям сведения, необходимые для организации и участия в спортивных играх.

После предоставления согласия на обработку персональных данных другим пользователям бота, также предоставившим такое согласие, могут быть доступны:

  • имя пользователя в Telegram;
  • username в Telegram, если он указан пользователем;
  • информация о роли пользователя в игре;
  • информация о составе игры;
  • иные сведения, непосредственно связанные с организацией конкретной игры.

Имя и username организатора, участников и пользователей резерва открытой игры доступны другим пользователям бота, предоставившим согласие, ещё до присоединения этих пользователей к игре. Роль пользователя (организатор, участник, пользователь резерва или пользователь, просматривающий открытую игру) на видимость имени и username не влияет.

Username отображается как ссылка на профиль пользователя в Telegram.

Пользователи, не предоставившие согласие, доступа к функциям и данным игр не получают.

NaParu не публикует в игровых карточках:

  • паспортные данные;
  • адрес проживания;
  • номер телефона;
  • электронную почту;
  • медицинские сведения;
  • иные данные, не необходимые для организации игры.

7. Хранение персональных данных

Персональные данные хранятся в течение срока, необходимого для достижения целей их обработки, если более длительный срок не установлен законодательством Российской Федерации или иным законным основанием.

После достижения целей обработки данные подлежат удалению или обезличиванию, если их дальнейшее хранение не требуется или не допускается законодательством.

Для игровых данных может сохраняться обезличенная или техническая информация, необходимая для обеспечения целостности истории Сервиса, безопасности и выполнения требований законодательства.

8. Удаление персональных данных

Пользователь может запросить удаление своих персональных данных.

В предусмотренных Сервисом случаях пользователь может самостоятельно воспользоваться функцией «Мои данные» / «Удалить мои данные».

При удалении данных:

  • персональные данные пользователя удаляются либо обезличиваются в соответствии с технической возможностью и законодательными требованиями;
  • участие пользователя в будущих играх прекращается;
  • необходимые игровые записи могут быть обезличены;
  • данные, которые оператор обязан сохранять в соответствии с законодательством, могут сохраняться в течение установленного срока.

Удаление данных не должно приводить к удалению информации, которую оператор обязан хранить по закону.

9. Передача персональных данных

Персональные данные не продаются и не предоставляются третьим лицам для самостоятельного использования в рекламных или маркетинговых целях.

Передача персональных данных может осуществляться:

  • другим пользователям Сервиса — в объёме, необходимом для соответствующей функции NaParu;
  • поставщикам технической инфраструктуры — в объёме, необходимом для работы Сервиса;
  • государственным органам — если такая передача предусмотрена законодательством Российской Федерации или обязательным требованием уполномоченного органа.

При использовании сторонних сервисов для функционирования Telegram-бота обработка данных соответствующими сервисами может осуществляться на условиях и в соответствии с их собственными правилами обработки данных.

10. Безопасность персональных данных

Оператор принимает необходимые правовые, организационные и технические меры для защиты персональных данных от неправомерного или случайного доступа, уничтожения, изменения, блокирования, копирования, предоставления, распространения и иных неправомерных действий.

Доступ к данным ограничивается в соответствии с необходимостью выполнения соответствующих функций.

Пароли, токены доступа и иные технические секреты не публикуются и не предоставляются пользователям Сервиса.

11. Права пользователя

Пользователь имеет права, предусмотренные законодательством Российской Федерации, в том числе право:

  • получать сведения об обработке своих персональных данных;
  • требовать уточнения неточных данных;
  • требовать блокирования или удаления данных в предусмотренных законом случаях;
  • отозвать согласие на обработку персональных данных, если обработка основана на согласии;
  • обжаловать действия или бездействие оператора в установленном законом порядке.

Для реализации своих прав пользователь может обратиться к оператору по указанному в настоящей Политике адресу электронной почты.

12. Обращения по вопросам персональных данных

По вопросам обработки персональных данных, удаления или уточнения данных пользователь может обратиться:

E-mail: operator@bk.ru

В обращении рекомендуется указать:

  • имя пользователя;
  • Telegram username, если имеется;
  • суть обращения;
  • требуемое действие.

Оператор рассматривает обращения в порядке и сроки, предусмотренные законодательством Российской Федерации.

13. Изменение Политики

Оператор вправе изменять настоящую Политику при изменении законодательства, функциональности NaParu или порядка обработки персональных данных.

Актуальная версия Политики размещается по тому же адресу, по которому пользователю предоставляется доступ к настоящему документу.

При существенном изменении порядка обработки персональных данных пользователю может потребоваться повторно ознакомиться с Политикой и предоставить согласие.

14. Заключительные положения

Настоящая Политика является публичным документом и доступна пользователям NaParu без ограничения доступа.

Использование персональных данных осуществляется только в пределах целей и порядка, установленных настоящей Политикой и применимым законодательством Российской Федерации.
